# Bear Recorder

A simple web-based screen recorder that lets you capture your screen, preview the recording, and download it as a video file.

Click "start record" to begin, then "stop recording" to finish. The recorded video will appear in the page, and you can download it with one click.

Built with plain HTML, CSS, and JavaScript. No external dependencies required.
